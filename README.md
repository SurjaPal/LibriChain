## 🧠 Project Description

**LibriChain** is an educational, beginner-friendly smart contract that demonstrates how blockchain can be used to manage a **library system** — where books can be borrowed, returned, and tracked **without any centralized database**.  

It’s designed to help new Solidity developers understand core concepts like:
- Structs and arrays  
- Mappings  
- Events  
- Modifiers and access control  
- State updates and on-chain data storage  

This example runs directly on the **Celo Sepolia Testnet** and keeps the system intentionally simple — no input forms, gas-efficient minimalism, and human-readable code.

---

## ⚙️ What It Does

- Preloads a few sample books directly into the smart contract (no external database required).  
- Allows any user to **borrow the first available book** with a single transaction (no input needed).  
- Lets users **return all borrowed books** in one go.  
- Tracks borrowers, timestamps, and availability entirely **on-chain**.  
- Enables the contract owner to add new books.  
- Exposes read-only functions to view all books or check what you’ve borrowed.

---

## 🌟 Features

✅ **Beginner-Friendly Solidity Code** — Clear, commented, and easy to understand  
✅ **No Frontend Inputs Required** — Core actions need no parameters  
✅ **Transparent On-Chain Records** — Every borrow/return event is stored forever  
✅ **Event Logging** — Emits events for borrowing, returning, and ownership changes  
✅ **Upgradeable Design** — You can easily extend to ERC-721, IPFS metadata, or library management UI
